## 1. Aim

To identify and correct HTML errors by examining missing closing tags, incorrect element nesting, missing attributes, and improper indentation. The corrected webpage is tested using browser Developer Tools and an HTML validation tool.

## 2. Requirements

- Visual Studio Code
- Google Chrome or Microsoft Edge
- A web browser's Developer Tools
- An HTML validation tool, such as the W3C Nu HTML Checker
- A file named `index.html`

## 3. Procedure

1. Create a folder named `Assignment-2.4`.
2. Create an `index.html` file containing intentionally incorrect HTML.
3. Identify missing closing tags, incorrect nesting, and missing attributes.
4. Open the webpage in a browser.
5. Open Developer Tools by pressing `F12`.
6. Select the **Elements** panel to inspect the browser's parsed HTML structure.
7. Correct the errors in VS Code.
8. Validate the corrected HTML using the W3C Nu HTML Checker.
9. Save the corrected file and refresh the browser.
10. Capture screenshots of the fixed webpage and, if possible, the validation results.

## 4. Errors Identified

| No. | Error                                     | Correction                                           |
| --- | ----------------------------------------- | ---------------------------------------------------- |
| 1   | Missing closing `</title>` tag            | Added the closing tag.                               |
| 2   | Missing closing `</h1>` tag               | Added the closing tag.                               |
| 3   | Paragraph opened inside another paragraph | Closed the first paragraph before starting the next. |
| 4   | Missing `alt` attribute on an image       | Added descriptive alternative text.                  |
| 5   | Missing `href` attribute on a link        | Added a valid destination.                           |
| 6   | Incorrect nesting of HTML elements        | Rearranged elements into a valid structure.          |
| 7   | Poor indentation                          | Formatted the code consistently.                     |

## 5. Tools Used

**Browser Developer Tools:** Used the Elements panel to inspect the HTML structure generated by the browser and identify unexpected nesting.

**W3C Nu HTML Checker:** Used to detect markup errors and warnings in the corrected HTML document.

Validation reference: [https://validator.w3.org/nu/](https://validator.w3.org/nu/)

## 6. Result

Successfully identified and corrected the intentional HTML errors, improved code indentation, inspected the webpage using browser Developer Tools, and checked the corrected markup using an HTML validation tool.
